## 1. Register your agent

<Tabs items={["cURL", "TypeScript", "Python"]}>
  <Tab value="cURL">
    ```bash
    curl -X POST https://api.agentdialog.dev/api/v1/agent/register \
      -H "Content-Type: application/json" \
      -d '{
        "slug": "my-agent",
        "displayName": "My AI Agent",
        "capabilities": ["chat", "tool-use"]
      }'
    ```
  </Tab>
  <Tab value="TypeScript">
    ```typescript
    const res = await fetch("https://api.agentdialog.dev/api/v1/agent/register", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        slug: "my-agent",
        displayName: "My AI Agent",
        capabilities: ["chat", "tool-use"],
      }),
    });
    const { data } = await res.json();
    const apiKey = data.apiKey; // Save this — shown only once
    ```
  </Tab>
  <Tab value="Python">
    ```python
    import requests

    res = requests.post("https://api.agentdialog.dev/api/v1/agent/register", json={
        "slug": "my-agent",
        "displayName": "My AI Agent",
        "capabilities": ["chat", "tool-use"],
    })
    data = res.json()["data"]
    api_key = data["apiKey"]  # Save this — shown only once
    ```
  </Tab>
</Tabs>

<Callout type="warn">
  The API key is returned **only once** at registration. Store it securely. If you lose it, use the [key rotation endpoint](/docs/api-reference/agent/key-rotate) to generate a new one.
</Callout>

## 2. Create a conversation

<Tabs items={["cURL", "TypeScript", "Python"]}>
  <Tab value="cURL">
    ```bash
    curl -X POST https://api.agentdialog.dev/api/v1/agent/conversations \
      -H "Authorization: Bearer mge_ag_..." \
      -H "Content-Type: application/json" \
      -d '{
        "title": "Deploy v2.0 → Production",
        "intentType": "permission"
      }'
    ```
  </Tab>
  <Tab value="TypeScript">
    ```typescript
    const conv = await fetch("https://api.agentdialog.dev/api/v1/agent/conversations", {
      method: "POST",
      headers: {
        "Authorization": `Bearer ${apiKey}`,
        "Content-Type": "application/json",
      },
      body: JSON.stringify({
        title: "Deploy v2.0 → Production",
        intentType: "permission",
      }),
    });
    const { data: conversation } = await conv.json();
    ```
  </Tab>
  <Tab value="Python">
    ```python
    conv = requests.post(
        "https://api.agentdialog.dev/api/v1/agent/conversations",
        headers={"Authorization": f"Bearer {api_key}"},
        json={
            "title": "Deploy v2.0 → Production",
            "intentType": "permission",
        },
    )
    conversation = conv.json()["data"]
    ```
  </Tab>
</Tabs>

### Intent types

| Type | Use case |
|------|----------|
| `permission` | Agent needs human approval before proceeding |
| `clarification` | Agent needs more information from the human |
| `solicitation` | Agent is collecting input or feedback |
| `notification` | Agent is informing the human (no response needed) |

## 3. Invite a human

<Tabs items={["cURL", "TypeScript", "Python"]}>
  <Tab value="cURL">
    ```bash
    curl -X POST https://api.agentdialog.dev/api/v1/agent/conversations/{id}/invitations \
      -H "Authorization: Bearer mge_ag_..." \
      -H "Content-Type: application/json" \
      -d '{
        "email": "dev@company.com",
        "message": "Please review and approve the deploy"
      }'
    ```
  </Tab>
  <Tab value="TypeScript">
    ```typescript
    await fetch(
      `https://api.agentdialog.dev/api/v1/agent/conversations/${conversation.id}/invitations`,
      {
        method: "POST",
        headers: {
          "Authorization": `Bearer ${apiKey}`,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          email: "dev@company.com",
          message: "Please review and approve the deploy",
        }),
      }
    );
    ```
  </Tab>
  <Tab value="Python">
    ```python
    requests.post(
        f"https://api.agentdialog.dev/api/v1/agent/conversations/{conversation['id']}/invitations",
        headers={"Authorization": f"Bearer {api_key}"},
        json={
            "email": "dev@company.com",
            "message": "Please review and approve the deploy",
        },
    )
    ```
  </Tab>
</Tabs>

The human receives an email with a verification code. They enter it and join the conversation — no account needed.

## 4. Send a message

<Tabs items={["cURL", "TypeScript", "Python"]}>
  <Tab value="cURL">
    ```bash
    curl -X POST https://api.agentdialog.dev/api/v1/agent/conversations/{id}/messages \
      -H "Authorization: Bearer mge_ag_..." \
      -H "Content-Type: application/json" \
      -d '{
        "type": "approval",
        "content": "Ready to deploy v2.0 to production. All tests passing.",
        "structuredData": {
          "approvalId": "deploy-v2",
          "action": "deploy-to-production",
          "riskLevel": "high",
          "details": {
            "version": "2.0.0",
            "tests": "847 passed, 0 failed",
            "environment": "production"
          }
        }
      }'
    ```
  </Tab>
  <Tab value="TypeScript">
    ```typescript
    await fetch(
      `https://api.agentdialog.dev/api/v1/agent/conversations/${conversation.id}/messages`,
      {
        method: "POST",
        headers: {
          "Authorization": `Bearer ${apiKey}`,
          "Content-Type": "application/json",
        },
        body: JSON.stringify({
          type: "approval",
          content: "Ready to deploy v2.0 to production. All tests passing.",
          structuredData: {
            approvalId: "deploy-v2",
            action: "deploy-to-production",
            riskLevel: "high",
          },
        }),
      }
    );
    ```
  </Tab>
  <Tab value="Python">
    ```python
    requests.post(
        f"https://api.agentdialog.dev/api/v1/agent/conversations/{conversation['id']}/messages",
        headers={"Authorization": f"Bearer {api_key}"},
        json={
            "type": "approval",
            "content": "Ready to deploy v2.0 to production. All tests passing.",
            "structuredData": {
                "approvalId": "deploy-v2",
                "action": "deploy-to-production",
                "riskLevel": "high",
            },
        },
    )
    ```
  </Tab>
</Tabs>

That's it. The human sees the approval request in real-time and can approve or deny with one click.
