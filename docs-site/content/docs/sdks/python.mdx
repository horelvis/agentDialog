## Quick example

The client class is `AgentDialog`. Methods take snake_case keyword arguments and
return typed dataclasses, not dictionaries.

```python
from agentdialog import AgentDialog

client = AgentDialog("mge_ag_...")

conv = client.create_conversation(
    title="Data Analysis Complete",
    intent_type="notification",
)

client.invite_human(conv.id, email="analyst@company.com", role="reviewer")

client.send_message(
    conv.id,
    type="form",
    content="Configure analysis parameters",
    structured_data={
        "formId": "config-001",
        "title": "Analysis Parameters",
        "fields": [
            {"name": "dataset", "type": "select",
             "label": "Dataset", "options": ["prod", "staging"]},
            {"name": "limit", "type": "number",
             "label": "Row limit", "defaultValue": 1000},
        ],
    },
)
```

Registering a new agent returns a client already holding the credentials:

```python
client = AgentDialog.register(slug="my-bot", display_name="My Bot")
print(client.agent.api_key)   # shown once — store it
```

## What the client covers

| Area | Methods |
|------|---------|
| Profile | `get_profile`, `update_profile`, `rotate_api_key` |
| Conversations | `create_conversation`, `get_conversation`, `update_conversation`, `list_conversations`, `list_all_conversations` |
| Messages | `send_message`, `list_messages`, `list_all_messages` |
| Invitations | `invite_human`, `list_invitations`, `revoke_invitation` |
| Webhooks | `create_webhook`, `list_webhooks`, `update_webhook`, `delete_webhook` |

`list_all_conversations` and `list_all_messages` are generators that page through
results for you.

## Using the API directly

Everything the SDK does is a REST call, and human queries — which the SDK does
not wrap yet — are three endpoints:

```python
import requests, time

BASE = "https://api.agentdialog.io/api/v1"
headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json",
}

# Ask a human. Returns immediately; they get an email and answer in the app.
created = requests.post(f"{BASE}/agent/queries",
    headers=headers,
    json={
        "query_type": "validation",
        "question": "Deploy v2.3 to production?",
        "context": "12 commits since the last release. All checks green.",
        "target_human_email": "oncall@example.com",
        "timeout_minutes": 120,
    },
).json()["data"]

query_id = created["query_id"]

# Poll for the answer. Wait 10-30 seconds between checks.
while True:
    query = requests.get(f"{BASE}/agent/queries/{query_id}", headers=headers).json()["data"]
    if query["status"] in ("answered", "expired"):
        break
    time.sleep(15)

print(query["status"], query["answer"])
```

The queries resource is snake_case on the wire. See the
[queries API reference](/docs/api-reference/agent/queries) for every field, and
[human queries](/docs/concepts/queries) for how the flow works.

An approval, using the same pattern:

```python
conv = requests.post(f"{BASE}/agent/conversations",
    headers=headers,
    json={"title": "Security Scan", "intentType": "permission"},
).json()["data"]

requests.post(
    f"{BASE}/agent/conversations/{conv['id']}/messages",
    headers=headers,
    json={
        "type": "approval",
        "content": "Found 2 critical vulnerabilities. Patch now?",
        "structuredData": {
            "approvalId": "patch-001",
            "action": "apply-security-patch",
            "riskLevel": "critical",
        },
    },
)
```

Note the difference: `/agent/queries` uses snake_case, while the older
conversations and messages endpoints use camelCase.

## WebSocket

```python
import asyncio, websockets, json

async def listen(api_key: str, conversation_id: str):
    async with websockets.connect(f"wss://api.agentdialog.io/ws?token={api_key}") as ws:
        await ws.send(json.dumps({"type": "subscribe", "conversationId": conversation_id}))
        async for raw in ws:
            data = json.loads(raw)
            if data["type"] == "message.new":
                print(f"[{data['message']['senderType']}] {data['message']['content']}")

asyncio.run(listen("mge_ag_...", "conv_uuid"))
```
