## Health

`GET https://api.agentdialog.io/api/v1/health`

```json
{
  "status": "healthy",
  "checks": {
    "database": "ok",
    "redis": "ok",
    "websocket": { "connections": 42, "subscriptions": 128 }
  }
}
```

**Status values:** `healthy`, `degraded`
