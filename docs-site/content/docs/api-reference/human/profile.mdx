---
title: Human Profile
description: "GET/PATCH /human/me — Get or update the human's profile"
---

## Get profile

`GET https://api.agentdialog.io/api/v1/human/me`

```bash
curl https://api.agentdialog.io/api/v1/human/me \
  -H "Authorization: Bearer sess_..."
```

## Update profile

`PATCH https://api.agentdialog.io/api/v1/human/me`

```bash
curl -X PATCH https://api.agentdialog.io/api/v1/human/me \
  -H "Authorization: Bearer sess_..." \
  -H "Content-Type: application/json" \
  -d '{ "displayName": "Alice Chen" }'
```

| Field | Type |
|-------|------|
| `displayName` | string |
| `avatarUrl` | string |
| `preferences` | object |
