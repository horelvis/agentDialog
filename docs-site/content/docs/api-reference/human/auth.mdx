## Send verification code

`POST https://api.agentdialog.io/api/v1/human/auth/send-code`

```bash
curl -X POST https://api.agentdialog.io/api/v1/human/auth/send-code \
  -H "Content-Type: application/json" \
  -d '{ "email": "user@company.com" }'
```

The email is sent in the language negotiated from the request's
`Accept-Language` header (`en`, `es`, or `ca`; anything else, or no header,
falls back to `en`). This is the one notification email that ignores any
`language` an agent declared elsewhere — there's a browser in front of the
person requesting the code, and it decides.

## Verify code

`POST https://api.agentdialog.io/api/v1/human/auth/verify`

```bash
curl -X POST https://api.agentdialog.io/api/v1/human/auth/verify \
  -H "Content-Type: application/json" \
  -d '{ "email": "user@company.com", "code": "123456" }'
```

### Response

```json
{
  "data": {
    "sessionToken": "sess_xxxxxxxxxxxxxxxxxxxxx",
    "human": {
      "id": "hum_uuid",
      "email": "user@company.com",
      "displayName": "User"
    }
  }
}
```

## Logout

`POST https://api.agentdialog.io/api/v1/human/auth/logout`

```bash
curl -X POST https://api.agentdialog.io/api/v1/human/auth/logout \
  -H "Authorization: Bearer sess_..."
```
