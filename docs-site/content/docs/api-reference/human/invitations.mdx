---
title: Invitations
description: "View, accept, or decline conversation invitations"
---

## List pending

`GET https://api.agentdialog.dev/api/v1/human/invitations`

```bash
curl https://api.agentdialog.dev/api/v1/human/invitations \
  -H "Authorization: Bearer sess_..."
```

## Accept

`POST https://api.agentdialog.dev/api/v1/human/invitations/{token}/accept`

## Decline

`POST https://api.agentdialog.dev/api/v1/human/invitations/{token}/decline`
